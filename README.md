# 🤖 AI Learning Assistant

An AI-powered web application that helps beginner developers learn JavaScript through interactive lessons, AI-assisted learning, and intelligent code debugging.

## 🚀 Live Demo

https://di21r9s7dmq4q.cloudfront.net

---

## ✨ Features

- AI-powered programming assistant using AWS Bedrock
- Intelligent JavaScript code debugger
- Structured JavaScript learning path
- Learning progress tracking
- Secure user authentication
- Fully deployed on AWS

## ⚙️ Installation

Clone the repository

```bash
git clone <repository-url>
cd AI-Learning-Assistant
```

Install dependencies

```bash
cd frontend
npm install

cd ../backend
npm install
```

Configure AWS credentials and deploy the backend using the Serverless Framework.

Run the frontend

```bash
npm run dev
```
