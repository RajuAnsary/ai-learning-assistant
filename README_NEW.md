# 🤖 AI Learning Assistant

An AI-powered learning platform that helps beginner developers learn programming through interactive AI chat, intelligent code debugging, voice-enabled assistance, and structured learning paths.

## 🏆 AI for Bharat AWS Hackathon

Built using AWS cloud services to provide an interactive and scalable learning experience.

## ⚙️ Installation

Clone the repository

```bash
git clone <repository-url>
```

Install dependencies

```bash
cd backend
npm install

cd ../frontend
npm install
```

Configure AWS credentials inside `backend/.env`

```env
AWS_ACCESS_KEY_ID=your_key
AWS_SECRET_ACCESS_KEY=your_secret
AWS_REGION=us-east-1
BEDROCK_MODEL_ID=us.amazon.nova-micro-v1:0
```

Run the application

```bash
# Backend
npm start

# Frontend
npm run dev
```
